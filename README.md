# Español SRS — PWA 설치 안내

스페인어 문맥 기반 간격 반복(SRS) 학습 앱입니다. 폰 홈 화면에 설치해 앱처럼 쓸 수 있고, 한번 열어두면 오프라인에서도 복습이 됩니다.

## 파일 구성

```
index.html        앱 본체 (모든 로직 포함)
manifest.json     앱 이름·아이콘·테마 정의
sw.js             서비스워커 (오프라인 캐싱)
icons/            앱 아이콘 (192, 512, maskable, apple-touch)
spanish_sample.csv  문장 추가용 샘플 CSV
```

## 중요: PWA는 HTTPS에서만 설치됩니다

파일을 그냥 더블클릭해서 열면(`file://`) 서비스워커와 "홈 화면에 설치"가 동작하지 않습니다. 아래 중 하나로 **웹에 올려야** 합니다. 전부 무료입니다.

### 방법 1. GitHub Pages (추천, 영구 무료)

1. GitHub 계정 생성 후 새 저장소(repository) 만들기
2. 이 폴더의 파일들(`index.html`, `manifest.json`, `sw.js`, `icons/`)을 업로드
3. 저장소 Settings → Pages → Source를 `main` 브랜치 / 루트로 설정
4. 몇 분 뒤 `https://사용자명.github.io/저장소명/` 주소가 생김
5. 그 주소를 폰 브라우저에서 열기

### 방법 2. Netlify Drop (가장 빠름, 계정도 선택)

1. https://app.netlify.com/drop 접속
2. 이 폴더를 통째로 드래그 앤 드롭
3. 즉시 `https://...netlify.app` 주소 발급 → 폰에서 열기

### 방법 3. 내 컴퓨터에서 로컬 테스트만

```bash
cd 이폴더
python3 -m http.server 8000
```
같은 와이파이의 폰 브라우저에서 `http://컴퓨터IP:8000` 접속.
(단 localhost가 아니면 일부 브라우저는 설치를 막을 수 있어, 실제 설치는 방법 1·2 권장)

## 폰에 설치하기

- **Android (Chrome):** 주소를 열면 하단/메뉴에 "앱 설치" 또는 "홈 화면에 추가"가 뜸. 앱 안의 "홈 화면에 설치하기" 버튼으로도 가능.
- **iPhone (Safari):** 공유 버튼(□↑) → "홈 화면에 추가". iOS는 반드시 Safari로 열어야 함.

설치하면 아이콘이 생기고, 전체화면(주소창 없이)으로 실행됩니다.

## 학습 로직 (2026-07-29 개정)

간격 계산을 Anki 방식에 맞춰 다듬었습니다. **기존 진도는 그대로 유지되며, 다음 복습부터 새 로직이 적용됩니다.**

- **간격**: 1일 → 3일 이후로는 난이도 계수(EF)를 곱해 늘어납니다. 이전의 1/3/7/21일 고정 사다리와 21→61일 급등이 없어졌습니다.
- **등급 반영**: "가물가물"은 완만하게(×1.2), "완벽"은 보너스(×1.15)를 받습니다. 이전에는 둘의 결과가 같았습니다.
- **실패 처리**: 처음부터 다시 시작하지 않고, 기존 간격의 40%(최소 1일)로 복귀합니다. 재학습에 성공하면 그 간격으로 돌아갑니다.
- **분산**: 같은 날 도입한 카드가 몇 달 뒤 한꺼번에 몰리지 않도록 간격에 ±5% 편차를 줍니다.
- **밀린 복습 우선**: 하루 상한을 넘긴 항목은 오래 밀린 순서대로 다음 세션에 먼저 나옵니다.
- **신규 자동 조절**: 밀린 복습이 많은 날은 신규 도입을 자동으로 줄입니다.
- **자동 보류**: 누적 8회 실패한 카드는 잠시 보류되고, 홈에서 다시 켤 수 있습니다.
- **문장 트랙**: 단어를 한 번 맞힌 다음 날부터 열립니다.

## 채점과 실행취소

- 채점 결과 화면의 **실행취소** 버튼으로 직전 채점을 완전히 되돌릴 수 있습니다. 오타로 틀렸을 때 간격이 깎이지 않습니다.
- 오답이 정답과 1~2글자 차이면 "오타 같아요"로 알려주고, 버튼 라벨이 "오타였어요 (되돌리기)"로 바뀝니다.
- 틀린 글자를 색으로 표시해 어디가 달랐는지 바로 보입니다.
- 대소문자 차이 / 악센트 차이 / `ñ`↔`n` 차이를 각각 구분해 안내합니다.
- 입력창 아래 `á é í ó ú ü ñ ¿ ¡` 빠른 입력 버튼이 있습니다.
- 빈 칸으로 확인을 눌러도 오답 처리되지 않습니다.

## 연속 학습

하루를 건너뛰어도 연속 학습이 유지됩니다(이틀 이상 비면 초기화). 홈에 "이번 주 N일"도 함께 표시됩니다.

## 데이터 저장에 대해

학습 진도는 그 브라우저의 `localStorage`에 저장됩니다. 즉 같은 주소를 같은 폰·같은 브라우저로 열면 이어집니다. 기기를 바꾸거나 브라우저 데이터를 지우면 진도가 초기화되니, 홈의 "진도 백업 / 복원"으로 주기적으로 백업해두는 걸 권합니다.

백업 CSV에 실패 횟수·성공 횟수·보류 여부 컬럼이 추가됐습니다. **이전 버전에서 만든 백업 파일도 그대로 복원됩니다.**

## 문장 추가

앱 홈의 "CSV로 문장 추가"에서 CSV 파일을 넣으면 됩니다. 형식은 첫 줄이 헤더:

```
es,blank,ko,word,hint
```

- `es` 스페인어 문장 (필수)
- `blank` 빈칸으로 만들 단어 — 문장에 그대로 포함돼야 함 (필수)
- `ko` 한국어 뜻 (필수)
- `word` 핵심 단어 뜻 (선택)
- `hint` 영어 힌트 (선택)

쉼표·따옴표가 든 문장은 큰따옴표로 감싸면 됩니다. 한글이 깨지면 CSV를 UTF-8로 저장하세요.

이미 등록된 문장은 자동으로 건너뜁니다. 같은 파일을 두 번 넣어도 중복 카드가 생기지 않습니다.
